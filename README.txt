ERIC PERSONAL WEBSITE

Files
- index.html: the complete responsive homepage, including all styling.
- assets/: optimized portfolio preview images for the three example websites.

How to use
1. Keep index.html and the assets folder together.
2. Open index.html in any browser.
3. Upload the full folder to your web host, with index.html as the main homepage.
4. Replace the sample projects later as your real portfolio grows.
